# 📚 BIBLIOTRACK

Sistema de gestión bibliotecaria desarrollado para el curso de Arquitectura de Software E195.

## 🚀 Aplicación en línea

🔗 **Acceder a Bibliotrack:** https://book-track-suite.lovable.app/login

---

## ✨ Funcionalidades principales

* 👤 Registro e inicio de sesión de usuarios
* 📚 Gestión de catálogo de libros
* 🔄 Préstamos, devoluciones y renovaciones
* 📝 Reservas en línea
* 🔔 Notificaciones automáticas
* 📊 Generación de reportes

---

## 🛠️ Tecnologías utilizadas

* React
* TypeScript
* Lovable
* Supabase
* Tailwind CSS

## 🎯 Objetivo

Bibliotrack es una plataforma diseñada para optimizar la gestión de bibliotecas mediante la digitalización de procesos como el préstamo, devolución, reserva y administración de libros, mejorando la experiencia tanto para usuarios como para administradores.
